# A: マスを開けたときの飛散演出

## 目的

マスを開けたときに、マインクラフトのブロック破壊のような
「そのマスの色を拾った小さい四角が飛び散る」演出を加える。
開けた実感を出すのが狙いで、情報量を増やすためのものではない。

## 背景

盤面の描画は「背景色（パレット）＋ 下絵1枚の overlay」に刷新済み。
その際、100ms ごとに盤面81セルが再描画される問題を潰してある
（`TimerDisplay` への切り出しと `Cell` の `React.memo` 化）。

**この演出の実装でその成果を打ち消さないことが最重要。**

## 実装制約

**パーティクルを DOM 要素で作ってはいけない。**

1回の連鎖開放で数十セルが同時に開くため、セルごとに要素を足すと
一瞬で数百ノードが生成・破棄される。せっかく消した常時負荷が戻る。

盤面の上に `<canvas>` を1枚重ね、そこに描画すること。DOM要素は1つも増えない。

- キャンバスは盤面と同じ位置・サイズに絶対配置し、`pointer-events: none` にする
- 描画ループは `requestAnimationFrame`。パーティクルが0個になったらループを止める
  （回しっぱなしにするとバッテリーを食う）
- パーティクルの色は、開いたセルの色を `proposedColor(adjacentRed, adjacentBlue)` から取る。
  飛び散る破片が元のマスの色と一致していないと、演出として意味が通らない
- `prefers-reduced-motion` が指定されていたら演出を出さない
- 端末の DPR に合わせてキャンバスの実解像度を設定する。しないとぼやける
- ピクセルアートなので破片も角ばった四角にする。円にすると世界観が壊れる

## 触ってよいファイル

- `src/components/game/` 配下（新規コンポーネントの追加を含む）
- `src/hooks/` 配下（新規フックの追加）
- `src/app/game/game.module.css`

## 触ってはいけないファイル

- `src/lib/game-logic.ts` — ゲームのルールには手を触れない
- `src/lib/ice-colors.ts` — 色の設計は確定済み
- `src/app/globals.css` / `src/components/Icon.tsx` — レーンBが使う
- `src/app/page.tsx`, `ta/`, `result/`, `ranking/` — レーンBの担当
- `docs/PROJECT-STATUS.md`, `docs/ROADMAP.md` — 全レーン共通で編集禁止

## やること

1. 盤面に重ねるキャンバスのコンポーネントを作る
2. セルが開いたときに、そのセルの位置と色でパーティクルを発生させる。
   開いたセルは `revealCell` の戻り値（`{ type: "reveal", cells }`）で取れる。
   連鎖で複数開いた場合は全セルぶん出す
3. 破片は上に跳ねてから落ちる放物線。0.4〜0.6秒程度で消える
4. 連鎖で大量に開いたときは、1セルあたりの破片数を減らすなどして上限を設ける

## 完了条件

- マスを開けると破片が飛び、そのマスの色と一致している
- 連鎖で大量に開いてもカクつかない
- パーティクルが消えたあと `requestAnimationFrame` のループが止まっている
- `prefers-reduced-motion` で演出が出ない

## 検証

1. `npm run lint` と `npm run build` が通る
2. Netlify のデプロイプレビューを実機で開き、連鎖開放を何度も試してカクつかないか確認する
3. **盤面の DOM ノード数が演出の前後で変わらないことを確認する。**
   増えていたらパーティクルを DOM で作ってしまっている
