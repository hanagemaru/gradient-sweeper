## 3. 画面構成・遷移

| パス | 画面名 | 説明 |
|------|--------|------|
| `/` | Home | メイン画面 |
| `/ta` | Time Attack | 難易度選択 |
| `/game` | Game | ゲーム画面 |
| `/result` | Result | 最終結果 |
| `/ranking` | Ranking | ランキング表示 |

### 遷移フロー
```
Home → Endless開始 → Game
Home → Time Attack → /ta → 難易度選択 → Game
Home → Ranking
Game(ポーズ) → Quit → Home
Game(Endless・ミス) → GameOver → 復活 or あきらめる → Result
Game(TA・ゲームオーバー) → ホームに戻る → Home（結果画面なし）
Game(Endless・Clear) → 答え合わせ → ClearedModal（ボーナス演出）→ 次のレベルへ → Game
Game(TA・Clear) → 答え合わせ → Result
Result → スコア登録でRanking / スキップでHome
```

## 4. 操作仕様（スマホ）

### 4.1 タップ
- セルを開く

### 4.2 フラグ（スワイプ）
- セルに触れてスワイプでフラグON/OFF
- 角度：全方向OK
- 判定仕様：
  - 開始点からの移動距離が `cellSize` 以上でスワイプ成立
  - スワイプ判定はタップより優先
  - 成立した瞬間に確定（指を離すのを待たない）
  - スワイプ成立時はセルを開かない

## 5. 基本ルール

- **勝利条件**: 爆弾以外のセルをすべて開く
- **連鎖**: 隣接爆弾総数（r+b）が0なら周辺を再帰的に開く
- **セル状態**: `hidden` | `revealed` | `flagged` | `exploded`

### 盤面サイズ
- 9x9 固定

### 爆弾配置
- 赤爆弾と青爆弾はランダム比率で配置

## 6. 色決定ルール

隣接8マスの爆弾数を `r`（赤）、`b`（青）とする。

```typescript
function getCellColor(r: number, b: number): [number, number, number] {
  // r==0 && b==0 → 白
  if (r === 0 && b === 0) return [255, 255, 255];
  
  const t = (r + b) / 8;
  
  // base（G=0固定）
  let base: [number, number, number];
  if (r >= b && r > 0) {
    base = [255, 0, Math.round(255 * (b / r))];
  } else {
    base = [Math.round(255 * (r / b)), 0, 255];
  }
  
  // color = (1-t)*255 + t*base
  return base.map((ch) => 
    Math.min(255, Math.max(0, Math.round((1 - t) * 255 + t * ch)))
  ) as [number, number, number];
}
```

## 7. ゲームモード

### 7A. Endless モード

| 項目 | 仕様 |
|------|------|
| 爆弾数 | 3開始、クリアごと+1、最大80 |
| クリア後 | 答え合わせ表示 → ClearedModal（ボーナスカウント演出）→ 「次のレベルへ」で次面 |
| タイマー | 廃止（スコアに時間は影響しない） |
| 初期残機 | 3 |

#### ミス時の挙動
1. 残機 -1
2. 踏んだマスだけ未開に戻す
3. 盤面維持、タイマー継続
4. ミス数をカウント

#### 残機切れ時
- リワード広告視聴 → 残機3回復して続行
- あきらめる → 終了 → Result画面へ

#### スコアリング（リアルタイム加算方式）
- セル開放: +100 × 現在レベル（flood fillで複数開いた場合、全セル分加算）
- スピードボーナス: 直前のセル開放から1秒以内に次のセルを開くと追加ボーナス（1セル分基準）。連続でコンボ（1回: ×0.5, 2回: ×1.0, 3回: ×1.5, 4回以上: ×2.0）
- レベルクリアボーナス: +1,000 × 現在レベル（ClearedModal演出後に加算）
- パーフェクトボーナス: そのレベルでミスなしクリア時のみ +1,000 × 現在レベル（同上）
- ミスペナルティ: -10,000（固定）
- 復活ペナルティ: なし（広告視聴ハードル低減のため）
- スコア下限: 0（マイナスにはならない）
- タイマー: 廃止（スコアに時間の影響なし）

#### ランキング
- 登録タイミング: 終了時（あきらめた時）
- ソート: スコア降順
- 表示: Top100

### 7B. Time Attack モード

| 難易度 | 爆弾数 |
|--------|--------|
| Easy | 10 |
| Mid | 20 |
| Hard | 30 |

| 項目 | 仕様 |
|------|------|
| タイマー | 開始〜クリア（ポーズ中停止） |
| 初期残機 | なし（残機概念を使わない） |
| 復活回数 | 最大2回まで（3ミスで終了） |

#### ミス時の挙動
1. 復活回数が残っている場合はゲームオーバー画面表示
2. リワード広告で復活（最大2回、+30秒ペナルティ）or ホームに戻る
3. 復活時：踏んだマスだけ未開に戻し、タイマー継続
4. 復活回数を使い切った状態でミスした場合も「ホームに戻る」でHomeへ（Result画面は表示しない）

#### スコアリング（タイムのみ方式）
- スコアの概念を廃止、タイムのみで競う
- 復活ペナルティ: +30秒（全難易度統一）
- 最終タイム = プレイ時間 + (復活回数 × 30,000ms)

#### ランキング
- 登録タイミング: クリア時のみ
- ソート: タイム昇順（短い方が上位、難易度別）
- 表示: 各難易度 Top100

## 8. ポーズ機能

- 盤面を隠す（オーバーレイ表示）
- タイマー停止
- 操作無効
- Quit選択時はResultを経由せずHomeへ直接遷移（スコア登録なし）

## 9. Result画面

### 表示項目

#### エンドレスモード（シンプル表示）
- 到達レベル
- ミス数
- スコア（強調表示）

#### タイムアタックモード（シンプル表示）
- 最終タイム（強調表示）
- ペナルティ内訳（プレイ時間・+ペナルティ）は復活した場合のみ表示

### プレイヤー名入力
- 任意入力（最大50文字）
- LocalStorageに保存
- 未入力の場合は "Anonymous" として表示

### スコア計算式

#### エンドレスモード（リアルタイム加算方式）
```
セル開放:           +100 × 現在レベル（per cell）
スピードボーナス:    1秒以内連続開放で追加（1セル分×コンボ倍率 0.5〜2.0）
レベルクリアボーナス: +1,000 × 現在レベル（次レベルへ進むときに加算）
パーフェクトボーナス: ミスなしクリア時 +1,000 × 現在レベル（同上）
ミスペナルティ:     -10,000（固定）
復活ペナルティ:     なし
下限:              0
```

- セルを開くたびにリアルタイムでスコア加算
- flood fillで複数セルが開いた場合、全セル分加算。スピードボーナスはクリックした1セル分のみ基準
- レベルクリア・パーフェクトボーナスはClearedModalで演出後に加算
- タイマー廃止（時間はスコアに影響しない）

#### タイムアタックモード（タイムのみ方式）
```
最終タイム = プレイ時間 + (復活回数 × 30,000ms)
```

- スコアの概念を廃止
- ミス → 即ゲームオーバー（現行維持）
- 復活 → +30秒ペナルティ（全難易度統一）
- ランキングはタイム昇順（短い方が上位）

### アクション
- ランキング登録（名前入力 or スキップ）
- 登録成功後はRankingへ自動遷移
- スキップ時はHomeへ直接遷移
